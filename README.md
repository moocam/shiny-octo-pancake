# Ted Plays Lead

A phone web app that teaches lead guitar: 10 lessons with playable tabs, a "Check me" mode that listens through the mic and checks each note, chord diagrams, jam tracks, a mic tuner and a metronome.

Everything is in `index.html` (no build step). Lesson progress is saved in the phone's browser.

## Publish with GitHub Pages
Settings → Pages → Build and deployment → Source: **Deploy from a branch** → pick the branch and `/ (root)` → Save.
The site appears at `https://<user>.github.io/shiny-octo-pancake/` after a minute or two. The mic only works over https, which Pages provides.

On the phone: open the link, then Share → **Add to Home Screen** (iPhone) or ⋮ → **Add to Home screen** (Android).
